# Monorail Pilot

> Issue #28 · 驾驶 / 模拟 · 单局 ≤ 3 分钟 · 准时停靠每一站

## 🎮 玩法

驾驶单轨列车穿越城市轨道，准时停靠在每一站。加速/刹车由你掌控，到站精度决定星级评价。

- **首屏 3 秒进入**：闪屏动画后点击"开始驾驶"
- **单局 30~150 秒**：每关限时不同，超时即失败
- **6 个关卡**：从初学者环线到夜景特快，难度递增
- **核心循环**：加速 → 进站停靠 → 精确对位 → 抵达终点

## ⭐ 评分系统

- **3 星**：准时抵达 + 每站精准停靠（偏移 < 30 单位）
- **2 星**：准时抵达，部分站偏移较大
- **1 星**：完成关卡，但超时或停靠不佳

## ⌨️ 操作

| 输入 | 动作 |
|---|---|
| `↑` / `W` / `Space` | 加速 |
| `↓` / `S` | 刹车 |
| 屏幕右侧点击/触摸 | 加速（触屏/鼠标） |
| 屏幕左侧点击/触摸 | 刹车（触屏/鼠标） |
| `P` / `Esc` | 暂停 |
| `Enter` / 点击按钮 | 确认 |

## ✨ 反馈

- 加速引擎音、刹车音、到站"叮咚"、胜利/失败音效（Web Audio API 合成）
- `navigator.vibrate` 触觉震动（到站短震、失败长震、胜利脉冲震）
- 粒子效果：加速尾迹、到站闪光
