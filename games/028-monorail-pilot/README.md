# Monorail Pilot

A monorail train driving game where you control speed, stop at stations on time, and reach your destination to earn stars.

## How to Play

Drive the monorail along a neon-lit track. Each level has a set of stations with target arrival times. Accelerate or brake to arrive as close to the target time as possible — the closer you are, the more stars you earn!

### Controls

| Action | Keyboard | Touch |
|--------|----------|-------|
| Accelerate | Arrow Up / W | Hold ACCEL button |
| Brake | Arrow Down / S | Hold BRAKE button |
| Emergency Brake | Space | — |
| Continue / Start | Enter / Click | Tap button |

### Scoring

Each station awards up to 3 stars based on arrival accuracy:

| Stars | Margin | Points |
|-------|--------|--------|
| ★★★ | Within 0.5s of target | 300 |
| ★★ | Within 1.5s of target | 200 |
| ★ | Within 3.0s of target | 100 |
| ☆ | Missed | 0 |

### Routes

| Level | Name | Stops | Max Speed |
|-------|------|-------|-----------|
| 1 | Green Line | 3 | 160 km/h |
| 2 | Blue Line | 4 | 180 km/h |
| 3 | Red Line | 5 | 200 km/h |
| 4 | Purple Line | 5 | 220 km/h |

Complete a level to unlock the next route.
